## Correção mais recente

Durante a homologação, a abertura de Campanha funcionava no Espaço legado, mas
falhava no Espaço pessoal de validação com:

`Planejador responsável não é membro ativo do espaço`.

A causa foi confirmada no banco remoto:

- o perfil administrador é proprietário do Espaço legado;
- outro perfil ativo é proprietário do Espaço pessoal de validação;
- administradores podem selecionar espaços alheios;
- a interface enviava sempre o administrador autenticado como planejador,
  embora ele não fosse membro do espaço pessoal.

O commit `1387a4a` preserva a validação do banco e altera a interface para:

- usar o próprio usuário quando ele é proprietário ou membro;
- usar o proprietário ativo como planejador padrão quando um administrador
  atua em espaço alheio;
- exibir `Proprietário do espaço` nesse caso;
- preservar a autoria da operação no administrador autenticado.

O reteste funcional na hospedagem ainda deve ser marcado explicitamente como
aprovado no issue do piloto.
